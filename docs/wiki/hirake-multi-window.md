複数ウィンドウ（**Ctrl+N**）と、起動時に前回の状態へ戻す仕組み。

## 何がウィンドウ単位で、何がアプリ全体か

| 対象 | 範囲 |
|---|---|
| タブ構成・アクティブタブ・スクロール位置 | ウィンドウ単位 |
| ウィンドウの位置とサイズ | ウィンドウ単位 |
| ワークスペースの所属 | ウィンドウ単位（1 ワークスペース = 1 ウィンドウ） |
| **テーマ** | **アプリ全体で共通** |
| **ズーム倍率** | **アプリ全体で共通**（全タブに反映） |

同時に開けるウィンドウは 10 枚まで。

## セッション復元

引数なしで起動すると前回開いていたタブを復元する。

- **ウィンドウの枚数ごと復元される**（1 枚に畳まれない）
- **仮想タブも復元対象** — キャンバス・構造クエリ・指紋・統計。これらはファイルではなくフォルダに紐づくタブ
- ファイルごとのスクロール位置も復元される

名前を付けて明示的に保存する方は [[hirake-workspaces]]。

## 二重起動時の挙動

別の Markdown ファイルを開いても**新しいウィンドウを増やさず、既存のウィンドウに新しいタブとして追加**する。`hirake://` 経由でも同じで、複数ウィンドウがある場合の宛先は「そのファイルを開いているウィンドウ → 無ければ最後にアクティブだったウィンドウ」の順で決まる → [[hirake-uri-scheme]]。

例外は `hirake://workspace?name=`。こちらは 1 ワークスペース = 1 ウィンドウの規約に従い**新しいウィンドウ**で開く。
