「ただ表示するだけのビューアではない」を成立させている機能群。フォルダに溜まった Markdown を横断的に探索する。

## 前提: 完全オフライン

**すべてローカルで完結し、文書が外部へ送信されることはない。** 埋め込みモデルは ONNX でローカル実行し、OCR は Windows OCR を使う。社内文書を扱えることが設計の前提になっている。

**AI モデル未取得の環境では静かに無効化される。** モデルが無いことでアプリ全体が使えなくなったり起動が遅くなったりせず、ビューアとしての軽快さは損なわれない。この「あれば効く / 無ければ黙って消える」構えが探索機能全体の方針。

## 機能

| 機能 | ショートカット | できること |
|---|---|---|
| AI 意味検索 | — | 「認証まわりで例外的な扱いをしている箇所」のような曖昧な日本語で、キーワードが一致しない文書まで引き当てる |
| 画像内検索（OCR） | — | スクショや図の中の文字を抽出し、キーワード検索・意味検索の両方でヒットさせる |
| フォルダ内横断検索 | Ctrl+Shift+F | アクティブなファイルのフォルダ配下の `.md` / `.markdown` を再帰検索。ファイルごとにヒット行をプレビュー。文書が参照する画像内の文字（OCR）もヒット対象 |
| ナレッジグラフ | Ctrl+G | 文書間のリンクを解析して関係を可視化。**無限キャンバスの「全体俯瞰」として開く**（→ [[hirake-canvas]]）。バックリンク一覧を常設表示 |
| 構造クエリビュー | Ctrl+Shift+S | 全文書から「見出しだけ」「タスク（`- [ ]`）だけ」「TODO 等のキーワードを含むブロックだけ」を横断抽出 |
| 文書指紋・類似検出 | Ctrl+Shift+R | コピペそのまま・編集して貼った重複記述を検出してグループ表示。ドキュメント資産の重複を棚卸しできる |
| フォルダ統計ダッシュボード | Ctrl+Shift+T | ファイル数・文字数のサマリ、過去 365 日の更新ヒートマップ、開くたびに育つ推移グラフ、放置文書・ボリューム・未完了タスクのランキング |
| 「次に読む」レコメンド | — | 表示中の文書と意味的に似た文書をサイドバーに提案 |

## 共通の骨格

これらは独立した機能の寄せ集めではなく、**検索結果・一覧から該当行への直接ジャンプ**で相互につながっている。「一覧で見つける → クリックで本文の該当行へ」が全機能で共通の導線になっている。

同じ「該当位置へ飛ぶ」経路を外部アプリへ開いたものが [[hirake-uri-scheme]] の `line` / `heading` パラメータ。

## 走査の範囲

いずれの機能も、起点フォルダの配下を再帰的に走査する。**シンボリックリンク（ジャンクション）は既定では辿らない。**
リンクが `\\server\share` を指していると走査した瞬間に SMB 認証が飛び、「完全オフライン」の前提が崩れるため。

設定で辿るようにできるが、その場合も結果は**実体のパス**で返る。詳細は → [[hirake-directory-links]]

## タブとしての性質

キャンバス・構造クエリ・指紋・統計は**仮想タブ**として扱われ、ファイルではなくフォルダに紐づく。セッション復元とワークスペース保存の対象になる（→ [[hirake-multi-window]] [[hirake-workspaces]]）。
